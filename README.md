# STS2Guides

> The ultimate **Slay the Spire 2** guide & reference site — best builds, card tier lists, relic database, boss strategies, and co-op synergy guides.

**🌐 [sts2guides.com](https://sts2guides.com)**

## Features

- **5 Character Guides** — Ironclad, Silent, Defect, Necrobinder, Regent with build recommendations
- **Card Database** — 439 cards with tier ratings, effects, costs, and upgrade info
- **Relic Database** — 293 relics with tier, character, and synergy data
- **Boss Guides** — Act 1-4 boss patterns and counter strategies
- **Tier List** — S/A/B/C/D rankings for all cards
- **Build Guides** — In-depth strategy guides for each character
- **Co-op Guide** — Multiplayer mechanics and team synergies
- **Beginner's Guide** — From first run to consistent wins

## Tech Stack

- Pure static HTML/CSS/JS — no frameworks, no build step
- Hosted on Cloudflare Pages
- Dark theme, fully responsive (mobile + desktop)
- Client-side search with JSON index
- GDPR-compliant cookie consent

## Local Development

Open any `.html` file directly in a browser — no server required. The search index is pre-built in `en/search-index.json`.
