STS2 Steam Workshop: The Complete Player's Guide

~11 min read · Install mods, discover the best Workshop content, create your own

📅 Published: June 22, 2026 · Workshop launched with v0.107.1 (Jun 19)

What Steam Workshop Means for STS2

With v0.107.1 Major Update #2, Mega Crit flipped the switch on Steam Workshop integration. STS1's modding community is legendary (Downfall, Replay the Spire, Hubris), and STS2 is positioned to build an even richer ecosystem during Early Access — not years after launch. Mods can now influence development: Mega Crit can see what the community builds and integrate the best ideas into the main game.

Why EA Workshop Is a Big Deal: STS1 modders had to wait for full release; STS2 modders get to shape the game alongside the devs. The 136K concurrent player spike is partly driven by Workshop curiosity.

How to Install Mods

  1. Open Steam → Slay the Spire 2 → Workshop tab.
  2. Browse or search for mods. Filter by: Most Subscribed, Most Recent, Top Rated.
  3. Click a mod → green "Subscribe" button. Steam handles the download.
  4. In-game: Main Menu → Mods. Enable/disable mods from the mod management screen.
  5. Restart if prompted. Some mods need a restart to fully activate.
Important: Back up your save before installing content mods. Steam Cloud sync can conflict with modded saves. Also, run a few vanilla runs first if you care about your official win rate.

How to Create Your Own Mods

STS2 modding uses a Lua-based scripting API (similar to STS1 with expanded hooks). Mega Crit published official modding documentation covering the full API.

  1. Download the Modding Toolkit from the STS2 Workshop ("STS2 ModKit").
  2. Create a mod folder under Steam/steamapps/common/SlayTheSpire2/mods/.
  3. Write your modinfo.lua — defines mod name, description, and dependencies.
  4. Script content using the STS2 Mod API (cards, relics, characters, events, enemies are all hookable).
  5. Test locally with the --mods-enabled launch option.
  6. Upload via the in-game Mod Publisher (Main Menu → Mods → Publish).
Pro Tip: Start small — a single custom card or relic — to learn the API. The most common mistake is trying to build a full character on day one. Ship something small, get feedback, iterate.

Mod Management Tips

ScenarioSolution
Game crashes after subscribingUnsubscribe, verify game files, re-subscribe one mod at a time to isolate the conflict
Two mods conflictCheck descriptions for incompatibilities. Use in-game load order manager
Mod causes save corruptionRestore from backup (Documents/My Games/SlayTheSpire2/backups), disable mod
Want to play vanilla againDisable all mods from Mods menu, restart. No need to unsubscribe
Mod isn't updatingUnsubscribe and re-subscribe to force fresh download

The Future of STS2 Modding

The STS1 modding scene produced Downfall — a mod so good it became official. With Workshop in Early Access, STS2's potential is even higher.
